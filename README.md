# ArcticDEMDownloader

## Версия 0.9

Добавлены SVG-иконки на панель инструментов QGIS:

- `icons/index.svg` — подгрузить индексы ArcticDEM;
- `icons/download.svg` — скачать выбранные тайлы;
- `icons/vrt.svg` — создать VRT из папки DEM.

На панели отображаются только иконки. Старый текст сохранён как всплывающая подсказка при наведении и как пункт меню в `Модули → ArcticDEMDownloader`.



## Версия 0.8

Изменение по распаковке:

- по умолчанию плагин извлекает **все файлы из архивов**
- опция `Извлекать только DEM GeoTIFF` оставлена как дополнительный режим;
- VRT создаётся **только по DEM GeoTIFF (demi)**, даже если из архива извлечены также `count`, `mad`, `date`, `matchtag`, `browse` и другие файлы;


Сохранены функции:

- подгрузка встроенных shapefile-индексов;
- скачивание через HTTP Range;
- `.part`-сегменты;
- докачка после обрыва;
- пауза по каждому файлу;
- проверка полноты скачивания;
- автоматическое добавление VRT в проект QGIS.

## Как пользоваться

1. Установи ZIP как QGIS-плагин.
2. Открой:
   `Модули → ArcticDEMDownloader → Подгрузить индексы ArcticDEM`
3. Выбери 2 м, 10 м или 32 м.
4. Выдели нужные листы.
5. Выбери активным слой загруженных индексов
6. Открой:
   `Модули → ArcticDEMDownloader → Скачать выбранные тайлы`
7. Для полной распаковки оставь галочку `Извлекать только DEM GeoTIFF` выключенной.
8. Оставь включёнными:
   - `Автоматически распаковать архивы`
   - `Автоматически создать VRT после распаковки по DEM GeoTIFF`
   - `Добавить VRT в проект QGIS`
9. Нажми `Скачать`.

После завершения появится:

`ArcticDEM.vrt`

и он сам добавится в проект QGIS.

## Где будут распакованные файлы

Распакованные файлы будут здесь:

`выбранная_папка/extracted_files/`

## Что попадёт в VRT

В VRT попадут только DEM GeoTIFF-файлы, которые определяются по названию:

`*_dem*.tif`

Остальные файлы будут распакованы, но в VRT не включаются.
