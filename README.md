# ArcticDEMDownloader

## Версия 0.9

Добавлены SVG-иконки на панель инструментов QGIS:

- `icons/index.svg` — подгрузить индексы ArcticDEM;
- `icons/download.svg` — скачать выбранные тайлы;
- `icons/vrt.svg` — создать VRT из папки DEM.

На панели отображаются только иконки. Старый текст сохранён как всплывающая подсказка при наведении и как пункт меню в `Модули → ArcticDEMDownloader`.



## Версия 0.8

Изменение по распаковке:

- по умолчанию плагин извлекает **все файлы из архивов**
- опция `Извлекать только DEM GeoTIFF` оставлена как дополнительный режим;
- VRT создаётся **только по DEM GeoTIFF (demi)**, даже если из архива извлечены также `count`, `mad`, `date`, `matchtag`, `browse` и другие файлы;


Сохранены функции:

- подгрузка встроенных shapefile-индексов;
- скачивание через HTTP Range;
- `.part`-сегменты;
- докачка после обрыва;
- пауза по каждому файлу;
- проверка полноты скачивания;
- автоматическое добавление VRT в проект QGIS.

ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ ПЛАГИНА ARCTIC DEM DOWNLOADER

	---СКАЧИВАНИЕ---

1. Скачайте архив по ссылке https://github.com/voorooniin0401/ArcticDEMDownloader

2. Найдите и нажмите на зеленую кнопку "Code", в всплывающем окне выберите "Download ZIP"

	---УСТАНОВКА В QGIS---

1. Перейти вкладка "Модули" далее "Управление модулями"

2. Выбрать раздел слева "Установить из ZIP файла"

3. Найдите скачанный zip архив и нажмите кнопку "Установить модуль"

	Установка завершена. Инструменты для работы с плагином появятся в вкладке "Модули" подвкладка "ArcticDEMDownloader"
	
	---РАБОТА С ПЛАГИНОМ---
	
1. Подгрузите любую из подложек через модуль "NextGIS QuickMapServices". Рекомендую загрузить "Google" - "Google Hybrid"

2. Найдите на панели инструментов новые три иконки, или открой вкладку "Модули" подвкладка "ArcticDEMDownloader", выберите из выпадающего меню "Подгрузить индексы ArcticDEM"

3. Выберите необходимую Вам подложку, для более точной работы с рельефом рекомендую выбрать первый вариант "2 м - ArcticDEM_Mosaic_Index_v4_1_2m.shp"

4. После подгрузки у вас появится подложка с тайлами ArcticDEM. Ссылки на скачивание отдельных тайлов заключены в таблице атрибутов - атрибут "fileurl", 
	однако плагин ArcticDEMDownloader может сам начать скачивание выбранных тайла(ов). Для хорошей скорости скачивания предусмотрена многопоточное загрузка тайлов.

	---ШАГИ ДЛЯ СКАЧИВАНИЯ ТАЙЛОВ---

1. Сделайте слой подложки активным слоем, для этого в вкладке "Слои" нажмите на подложку "ArcticDEM Mosaic Index v4.1. 2 м"

2. Если у вас есть граница лицензии или иной интересующий вас контур в kmz/kml формате, то загрузите его, и выделите. 
	1 Способ "Выделение по расположению", "Выбрать объекты слоя" - Подложка ArcticDEM, по отношению к объектам слоя - Ваш контур.
	2 Способ "Выделить объекты", и выбрать тайлы на карте. Для выбора нескольких тайлов удерживайте кнопку CTRL
	
3. После выбора тайлов, во вкладке "Модули" подвкладка "ArcticDEMDownloader", выберите из выпадающего меню "Скачать выбранные тайлы"

4. Выберите папку для сохранения тайлов. Учтите, что загрузка идет многопоточно, могут создаваться одновременно 20-30 архивов, 
	по завершению скачивания они автоматически соберутся в один архив. 

5. Для обеспечения комфортной загрузки параметры по умолчанию можно ставить, единственное исходя из вашей цели вы можете включить "Извлекать только DEM GeoTIFF"
	что обеспечит быстрое скачивание ввиду загрузки только файла dem.tif (предназначенный для построения рельефа). Если не включать данный параметр, 
	то загрузится весь архив с серверов ArcticDEM. Если вам не нужно автоматически создавать и загружать в проект VRT после скачивания то можно снять галочку. 
	
После завершения загрузки тайла, он останется в указанной вами папке.
